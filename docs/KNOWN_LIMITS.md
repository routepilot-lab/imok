# imOK 已知限制

- 按设备接管同时最多启用 8 条设备策略。整网模式使用独立的网段选择。
- 同一台路由器的受管设备可以使用不同规则，代理流量共用当前主线路出口。独立手机客户端可分别选出口。
- 当前代理范围是 IPv4。IPv6 可阻断或由本地网络直连。
- Workers 备用代理 TCP。被选入代理的 UDP 会阻断。
- 已有安装的验证现场为 GL.iNet GL-MT6000、ARM64、OpenWrt 24.10。新机首次安装、APT 升级及其他硬件的验证见实机清单。
- 主线路依赖 Cloudflare 官方客户端。已验证的输出样本集中在 `2026.8.2115.0`，其他版本可能需要更新解析。
- 开启设备断网保护时，现有默认要求关闭软、硬件流量卸载。共存需先验证目标平台的流表与重载行为。
- 路由器发起的测速衡量路由器到出口的路径。LAN 设备的转发吞吐与硬件加速另测。

参见 [实机验收](HARDWARE_ACCEPTANCE.md)。
