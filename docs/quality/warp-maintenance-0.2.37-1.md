## 已验证

- Python 主套件 521 项、服务端 5 项及 18 组前端检查；发布工具保护 11 项测试单独运行，结果见 PUBLICATION_CHECKS.json。
- 目标缓存 LuCI 契约、资源内容哈希、语法、包文件权限及可复现双构建通过。
- 实际下载并核对固定官方 Debian ARM64 基础归档的大小、SHA-256 与目录结构；检查时没有执行归档中的 ARM64 程序。
- 模拟维护覆盖归档越界、错误架构／哈希／公钥、缓存过期与篡改、重复或过期确认、配置并行变化、异常身份、备份损坏、隔离权限、进程组超时与事务恢复。
- 1440、768、375、320 的隔离浏览器预览。真实桌面 Argon 验证总览与 WARP 页面，字体继承、导航、选中状态、按钮可用、无异常文本及整页溢出。
- 在已有 ARM64 OpenWrt 24.10 环境更新同版插件文件，59 个非用户配置数据文件与最终安装包一致；未执行会停启主线路的普通 IPK 升级钩子。
- 原网络进程、出口设置、持久配置、注册身份、WARP 二进制和流量历史保留；90 次连续采样通过；代理 Google / Cloudflare 与直连百度 HTTPS 检查通过。
- 真实页面提交官方版本检查，检查时间推进、任务成功、临时提交提示消失。默认每日调度实例运行，未自动安装或升级。
- 真实运行中的主线路拒绝维护；原程序备份校验、隔离恢复测试与实机只读回滚检查通过。

这些现场结果由维护者记录，不等于任意设备、组织或网络环境的独立认证。公开仓库 Actions 会另行运行源码测试、构建及附件哈希校验。

## 尚未验证

全新 WARP 首次安装、真实 ARM64 APT 安装／升级、运行环境回滚、CGI 上传、硬件断电恢复，尚未在独立测试设备完成。未新增 Windows、Safari、iOS、Android 真机和 200% 浏览器缩放验收。

自动下载与维护代码已有隔离测试，不因此宣称其全部实机流程成熟。目录检查、软件版本读取、隧道连接与网站可达性分别判断。

## 更新与回滚原则

1. 保留旧 IPK，另行保护私有配置和身份；普通设置导出不是完整运行环境备份。
2. 普通 IPK 安装可能短暂重连，预先准备独立本地管理连接。
3. 版本检查只查目录；安装、升级和回滚需关闭主线路、单独确认并通过上下文复核。
4. 受控热更新不会重新加载运行中进程。执行运行环境写入前，安排正常重启插件加载新保护，再关闭总开关维护。
5. 源码回退、插件降级和 WARP 运行环境恢复是不同操作。未完成的运行环境事务先恢复，不用旧插件绕过阻断。
6. 回滚拒绝未知后续修改，不覆盖当前身份、订阅或网络设置；不要在公开反馈中附带私有备份。
