# 历史手动运行环境安装

以下历史完整包流程仅适用于已经自行合法准备齐运行环境与校验文件的安装目录；GitHub 下载不包含第三方运行环境包。此段是历史离线方式，不是本版默认安装入口。不要在只有公开源码或 IPK 的目录直接运行此流程。

1. 解压完整 ZIP，把同一个安装目录放到路由器，不混入其他 IPK。不要在 Mac/Windows 上运行脚本。
2. 在路由器管理员 shell 运行 `sh install-router.sh --check`，只做平台、文件校验与空间检查。
3. 确认首次安装后运行 `sh install-router.sh --install`。已有运行环境会拒绝覆盖。
4. 通过当前 IPK 更新插件后，进入 Cloudflare 配置中心登录自己的账户、读取出口、选择范围，再手动开启总开关。

安装不是跨步骤事务。运行环境已解压但 IPK 失败时，先排查依赖，不删除原注册目录盲目重试。脚本只清理自己尚未提交的临时目录。完整旧包保留其当时版本，不能宣称它已包含当前修复。
