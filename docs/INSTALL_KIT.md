# imOK · Cloudflare 分流助手安装包

这个 ZIP 包含完整插件，可以保存、备份或分享。以 IPK 文件名中的版本号为准。

## 文件

- `luci-app-routepilot_版本_all.ipk`：完整插件安装／升级包。
- `imOK-版本-first-install.run`：带同版 IPK 的 iStore 首次安装文件（如本发行包附带）。
- `imOK-版本-reinstall-cn-keep-settings.run`：用于卸载后保留旧设置的 iStore 重装文件（如本发行包附带）。
- `imOK-版本-public-source.zip`：公开源码、测试和文档（如本发行包附带）。
- `packages/luci-app-routepilot/INSTALL.zh-CN.md`：中文详细安装指南。
- `本版更新.md`：新增功能、验证情况与边界。
- `LICENSE`、`THIRD_PARTY_NOTICES.txt`：许可和第三方说明。
- `SHA256SUMS`：本安装目录所有附件（校验文件自身除外）的 SHA-256。

公开包与截图不包含维护者真实租户、出口 IP、账号、私钥、Token、手机私密订阅、VPS 节点或用户配置。Cloudflare WARP 和 Debian 运行环境由路由器在线下载。

## 已经在使用 imOK 的路由器

1. 保存旧版本 IPK，先备份配置、个人规则和私人身份；备份中有凭据，不要一起分享。
2. 在电脑或路由器校验附件：`sha256sum -c SHA256SUMS`。macOS 可用 `shasum -a 256 -c SHA256SUMS`。
3. 只在兼容 OpenWrt 路由器，通过软件包管理上传并安装本版 IPK，或管理员 shell 执行 `opkg install /路径/本版.ipk`。不要在 Mac／Windows 执行安装。
4. 刷新 LuCI 页面，核对原入口、出口、接管范围和联网情况。升级可能短暂重连。
5. 如需回退，使用保留的旧 IPK 和针对该版本的备份方案；不要清空原注册目录或系统网络配置。

已有环境只升级插件，不要运行首次环境安装流程，不要卸载或重新申请身份来完成普通升级。

## 已卸载 imOK，保留旧设置后重装

如安装包附带 `reinstall-cn-keep-settings.run`，用本地管理连接在 iStore「手动安装」上传此文件。它优先使用清华镜像下载缺少的系统依赖，也会尝试南京大学镜像和官方源。发现旧配置仍标记为启用或登录准备时，先确认软件包已卸载、旧服务已停止，再备份旧配置并关闭这两个开关。安装完成后在总览核对账户、出口和设备设置，确认后再手动开启。备份保存在路由器上，路径见安装日志。

上传后核对任务窗口中的文件名。若窗口仍显示上一次的任务，先到「系统 → 软件包」检查 imOK 是否已经安装，并确认 iStore 当前没有运行任务。若本次文件没有开始安装，刷新「手动安装」后重新上传一次。若任务已成功但远程 LuCI 一时找不到 imOK 页面，等待菜单刷新后再从「服务」进入。

## 全新路由器

以 ARM64 OpenWrt 24.10 的 GL.iNet GL-MT6000 为例。先确认路由器能正常联网，且有约 1.6 GB 可用存储。

1. **上传一次安装文件。** 校验附件后，在 iStore「手动安装」上传 `imOK-版本-first-install.run`。安装器会下载缺少的系统依赖并安装 imOK。它优先尝试清华大学 TUNA 镜像，再试南京大学镜像和 OpenWrt 官方源，按当前固件版本和架构校验软件源签名。路由器原有软件源设置会保留。
2. **查看 WARP 安装进度。** 在符合条件的全新路由器上，首次安装文件会在插件装好后启动后台 WARP 安装。刷新 LuCI，打开「服务 → imOK → WARP 安装与更新」，可以看下载、校验和安装进度。若没有自动开始，点「自动下载并安装 WARP」并确认。中途失败时先看页面原因，再按提示重试。已有的下载文件会先校验，合格的文件可以复用。
3. **注册路由器并读取出口。** 看到「WARP 已安装」后点「下一步：登录 Cloudflare 账户」，在「账户与协议」保存自己的团队名称、准备登录环境并完成邮箱授权。路由器注册成功后等待出口目录读取完成。读取失败可在账户页重试。目录为空时先核对团队和 Cloudflare 出口配置。
4. **保存出口和接管范围。** 在「出口与分流」选择出口和接管范围，点「保存并应用」。如果选「按设备选择」，到「设备」保存至少一条已启用的代理策略。
5. **先测路由器，再开启接管。** 在登录准备期间，到「总览 → 首次设置」点「仅检测路由器 WARP 出口」，核对结果。准备好后点「结束登录准备」，再手动「开启 imOK」。隧道连上后点「检测实际出口地区」，并用一台已接管的设备打开网页确认。分流 DNS 开始运行后，可以到「DNS」检测解析。

没有 iStore 或只有 IPK 时，先在 LuCI「系统 → 软件包」点「更新列表」，成功后上传 IPK，再到「WARP 安装与更新」手动开始 WARP 安装。已有兼容环境可直接按上面的升级流程上传 IPK。

安装 WARP 只准备运行环境。邮箱授权、出口、接管范围和开启时间由你决定。需要单独检查文件、重新下载或分步安装时，展开「高级：查看下载文件与分步安装」。完整操作和故障排查见 `packages/luci-app-routepilot/INSTALL.zh-CN.md`。本版全新安装、注册到回滚的完整实机流程仍待验收。
