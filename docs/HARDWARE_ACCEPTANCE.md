- 兼容环境为 ARM64、OpenWrt 24.10 和已有 Cloudflare WARP 运行环境。
- 0.2.38-16 已在现有路由器从 0.2.38-15 升级。原分流与防火墙配置校验一致，MASQUE 恢复到原出口。局域网设备的 UDP、TCP DNS 查询及路由器五站检测通过。LuCI 总览、DNS 与 Workers 页面已核对。
