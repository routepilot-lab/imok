# imOK 2.0 · 设备自动填写与排版

**v0.2.37-3 预发布。** 保留 0.2.37-2 的 DNS、加载、诊断与备份兼容修复，加入设备页面的两项改进。

- 在「设备 → 添加」或「编辑」中，从「在线设备」选择设备后自动填写 MAC 地址和当前局域网 IPv4。字段可手动修改，需保存才能提交。
- 设备策略使用单一标题，新增按钮放在标题旁。启用状态、分流和 IPv6 选项使用中文，编辑和删除清晰区分，窄屏用带字段名的布局呈现。
- 逐台设置分流策略时，接管范围应选「按设备选择」。设备通过 DHCP 更换 IPv4 后可重新选择，或在路由器的 DHCP 设置中为设备保留地址。

## 安装与验证

安装包包含完整 IPK、公开源码、安装说明、许可和 SHA-256 校验文件。已有环境可在备份并保留旧 IPK 后安装新版插件。标准 IPK 升级可能短暂重连，回退方式见《开始阅读》。首次安装请先在「WARP 安装与更新」检测兼容性并准备官方组件，安装包不含第三方运行环境和私人配置。

设备页的自动填写、添加和编辑弹窗已经在路由器管理页面验证，排版检查覆盖 1440、1024、375 和 320 像素。打包使用独立测试和构建，检查记录位于源码中的 `docs/PUBLICATION_CHECKS.json`。延续上一版的预发布范围，全新 WARP 环境安装、APT 升级和运行环境恢复仍待独立实机验证。
