# imOK v0.2.38-32 · 本地测试版

<!-- release-status: local-test -->

修复全新设备的安装、注册和启用过程。iStore 首装包校验每个下载源，来源失败时尝试备用源。WARP 安装可以恢复失效的准备记录，重用已校验的下载。

账户页和总览在安装状态读取失败时提供重试。出口目录过期时保留已注册提示。刷新总览后可继续查看同一份已保存配置的近期出口预检结果。新机首次使用某种分流模式时，先准备该模式所需的规则。完整规则更新仍可单独执行。

全新设备请使用首装 `.run`。已有设备按[安装指南](../../packages/luci-app-routepilot/INSTALL.zh-CN.md)升级。真实邮箱授权、终端网络与回滚仍待独立同款路由器验收。
