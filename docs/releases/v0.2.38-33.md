# imOK v0.2.38-33 · 本地测试版

<!-- release-status: local-test -->

修复测试路由器上发现的三处状态显示问题。已注册的设备会看到检查账户或选择出口的提示。总览直接使用本机运行环境返回的 WARP 版本。分流关闭时，总览显示已保存的接管范围，开启后显示实际接管范围。

安装器在临时环境中校验依赖时同步已安装软件的文件清单。软件源签名和依赖约束继续由 opkg 检查。

首次安装请使用首装 `.run`。已安装设备按[安装指南](../../packages/luci-app-routepilot/INSTALL.zh-CN.md)操作。
