# imOK 2.0 · DNS、加载与备份兼容修复

**v0.2.37-2 预发布，本地完整安装包。** 包含全部现有插件功能及 2026-11-10 已验证修复，不是增量补丁或路由器固件。本次只生成本地附件，不安装路由器、不上传 GitHub。

## 本版修复

- DNS：允许合法特殊标签，避免误拒绝导致等待或重试；保留原始报文、分流匹配语义和长度、压缩指针等安全校验。
- 页面加载：总览提前并行读取已有状态，首次轮询复用请求；后续仍为 2 秒轮询。设备页只读取可选主机提示，取消无关协议初始化，提示失败仍可编辑原策略。
- 检测反馈：超时、证书错误、传输不完整不再误报成功；无效临时进度可恢复，有效进行中任务继续防重复。
- 备份兼容：自定义分流列表与既有单类最多 2000 条能力一致；导出时先校验可导入性及 256 KiB 总大小，超限明确报错，不截断。

## 备份范围

继续使用 v3 导出并兼容旧 v2/v3 导入，不新增数据范围。包含普通 UCI 设置、设备策略、DNS、自定义分流、规则来源/频率和入口偏好；个人规则新增/长期排除、WARP 维护检查频率、运行环境及历史、路由器身份和客户端独立凭据/私密订阅不在普通导出中，需单独保留。普通备份不能替代完整系统或身份备份。

## 安装及回退

已有环境：保留旧 IPK 和私有备份，核对 SHA-256 后通过 OpenWrt 软件包管理安装新 IPK，刷新 LuCI 并核对设置和连接。不要重新注册或重装运行环境来完成普通插件升级。标准 IPK 维护脚本可能短暂重连，远程升级需具备独立恢复管理方式。

需要回退时安装保留的旧 IPK，并按对应版本备份说明恢复；勿清空身份目录、覆盖运行环境或盲目恢复整机网络配置。详细安装步骤见公开源码中的 `packages/luci-app-routepilot/INSTALL.zh-CN.md`。
