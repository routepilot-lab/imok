# imOK v0.2.38-36 · 安装引导与主题适配

<!-- release-status: stable -->

## 这版更新

- **首次设置**。按安装 WARP、登录并读取账户出口、保存出口与接管范围、独立检测、手动开启的顺序引导。支持粘贴完整授权链接、含链接的网页源代码整行或 `token=` 后的令牌。
- **安装与恢复**。首装程序按固件匹配软件源、验证索引签名并补齐依赖。WARP 下载可查看分项进度，重试时复用已校验文件。已卸载且保留设置的设备有单独的重装文件。
- **连接与诊断**。区分账户目录、实际隧道、出口核对、网站检测和原出口恢复的结果。网站遇到短时网络错误时在同一路径重试一次。
- **界面**。imOK 跟随 Argon 当前浅色或深色模式，统一正文、表格、按钮、状态标签及弹窗的颜色。

## 下载和验证

下载 `imOK-0.2.38-36-install-kit.zip` 后先读「开始阅读」。已有 imOK 时，备份后安装同版 IPK。全新设备使用首装 `.run`。已卸载且保留旧设置时，使用重装 `.run`。

在 GL.iNet GL-MT6000（OpenWrt 24.10.4、ARM64）完成保留配置升级，核对了原 WARP 注册、出口、MASQUE 隧道、HTTPS 与 DNS。用 Argon 2.2.9.4 样式在 Chromium 检查了 14 页的桌面和手机布局，以及自动、强制浅色及强制深色模式。界面测试使用演示数据。

已对首次安装流程运行隔离模拟。全新设备上的邮箱注册、运行环境升级与恢复仍需按实际固件和网络环境验证。安装程序需联网获取组件，并要求自备 Cloudflare Zero Trust 团队及可用出口。
