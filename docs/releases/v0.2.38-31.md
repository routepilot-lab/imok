# imOK v0.2.38-31 · 本地测试版

<!-- release-status: local-test -->

新路由器可在 iStore「手动安装」上传一次 `imOK-0.2.38-31-first-install.run`。安装器校验插件及缺少的 OpenWrt 依赖。符合条件的全新安装会接着启动 WARP 运行环境安装，可在「WARP 安装与更新」查看进度。任务未启动时可在页面确认「自动下载并安装 WARP」。失败时可查看原因后重试。高级区域保留文件检查、单项重新下载和分步安装。

看到「WARP 已安装」后，可直接进入 Cloudflare 账户注册。注册由用户在 Cloudflare 完成邮箱授权。选好出口和接管范围并保存后，可在总览先检测路由器自己的 WARP 出口。结束登录准备并手动开启 imOK 后，再核对实际出口、受管设备联网和 DNS 解析。

已有兼容环境的设备可以直接上传同版 IPK 升级。完整操作见[安装说明](../../packages/luci-app-routepilot/INSTALL.zh-CN.md)。独立设备从全新安装到注册、联网和回滚的完整实机验收仍待完成，具体条件见[硬件验收清单](../HARDWARE_ACCEPTANCE.md)。
