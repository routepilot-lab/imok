# imOK 2.0 · 客户端接入与稳定性版

<!-- release-status: stable -->

把 Cloudflare WARP / MASQUE、已有全球出口与日常网络管理，整理成一个路由器和手机都能用的控制台。

## 这次新增了什么？

- **客户端接入正式加入。** 每台手机拥有独立 MASQUE 身份、地址与出口选择，不复制路由器私钥，不让路由器跟着手机换线。
- **两种导入方式都保留。** 可以直接导入／扫码，也可以使用固定私密订阅；参数更新后手机更新订阅，出口调整后重连。
- **端口、DNS、入口分别可选。** 默认 UDP 443，保留官方支持的其他 UDP 端口；地区由已部署云端出口决定。
- **13 个统一页面。** 延续总览的字体、层级与组件，客户端页头更紧凑，去掉重复主导航。
- **状态与交互修复。** 检测结果缺失不再保留旧成功，异常条目不再中断刷新；修复团队名校验、空 RPC 提示、慢速旧列表覆盖，以及 Workers 关闭／过期时的误导表述。

## 为什么借助 Cloudflare？

客户端先连接 Cloudflare，再按组织路由连接自有出口，减少对本地直连某台 VPS 的依赖；家中设备与独立手机可分别管理入口和出口。

如果只限制了本地到 VPS 公网 IP 的直连，而两端 Cloudflare 连接、路由和 VPS 出网仍正常，间接路径仍可能工作；目标网站拒绝 VPS 出口 IP、服务器停机或隧道路径不可用时仍会受影响。实际速度与可用性以自己的网络检测为准。

- 466 项主 Python、5 项服务端 Python、17 组前端、真实目标 LuCI 契约、资源哈希与可重复构建通过；发布工具的隔离保护测试另行运行。
- 13 页在 1440／768／375 像素检查，18 个模拟状态通过；键盘焦点、取消、模拟导出清除及客户端异步回归通过。

- 已有真实独立注册、美国出口绑定和私密订阅 HTTPS 同步验证。手机实际订阅导入、其他租户策略、其他硬件／系统、WireGuard 切换、长期负载和多 LAN 端到端未完全验证。
