# imOK v0.2.38-1 · 本地测试版

<!-- release-status: local-test -->

本地包用于验证本轮 DNS、线路测速和断网保护相关改动。单路径每方向的默认测速预算为 200 MB，批量上限为 1 GB。本轮测速界面提供下载测量。

入口候选测量使用现有 IPv4 候选。curl 支持 HTTP/3 时测 QUIC 握手，否则尝试 TCP/TLS 握手并标明传输方式。出口或协议对比会临时暂停受管设备的接管。完成、取消或配置变化后按已保存配置恢复。

英文目录覆盖导航、总览、设备策略和客户端接入的主要操作。其余条目保留中文源文。

实机准备、抓包口径和回滚步骤见[硬件验收清单](../HARDWARE_ACCEPTANCE.md)。直连卸载与断网保护的共存改动继续受实机验收约束。
