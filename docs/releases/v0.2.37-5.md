# imOK 2.0 · 收尾优化版

<!-- release-status: stable -->

**v0.2.37-5 正式插件版。** 总览仍每两秒读取状态。七日流量图和连接记录只在内容变化时重绘，数据不变时可保留键盘焦点。异常采样日期显示为空数据。构建在安装包内生成版本信息，省去源码回写和整目录复制。

「客户端接入」延续单团队授权，每个客户端可选 MASQUE 或 WireGuard，并从团队已部署的网络中独立选择出口。「设备」页继续显示支持的 GL.iNet 固件所记录的局域网设备累计上传、下载和合计用量。

下载 `imOK-0.2.37-5-install-kit.zip` 可取得完整 IPK、公开源码、安装说明、许可和 SHA-256 校验文件。已有兼容环境请先备份并留好旧版 IPK，常规安装可能短暂重连。独立实机对全新 WARP 安装、APT 升级和运行环境恢复的验收仍待完成。安装包和项目截图使用公开示例，不包含私人配置和凭据。
