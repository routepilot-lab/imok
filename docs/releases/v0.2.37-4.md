# imOK 2.0 · 客户端双协议与局域网设备流量

**v0.2.37-4 预发布。** 在路由器后台分别管理家中设备的分流和外出客户端的连接。

- **客户端各自选协议。** 在「客户端接入 → 新增客户端」选择 MASQUE 或 WireGuard。每条记录使用自己的注册和密钥；同一 Cloudflare 团队统一授权，可复用管理员配置的服务令牌，也可使用邮箱授权。已有记录保留原来的协议。
- **客户端各自选出口。** 注册后，从团队已部署的出口里选一个应用。例如一部手机使用 WireGuard 接入首尔，另一部使用 MASQUE 接入美国；原有路由器主线路和其他客户端不需要切换。换出口后重连该客户端即可。
- **按协议导入。** MASQUE 支持直接导入、扫码或固定私密订阅；WireGuard 支持配置文件、扫码或复制配置。入口、端口和 DNS 可以逐客户端设置。协议和端口不决定出口国家。
- **看清局域网设备用了多少流量。** 在「Cloudflare 配置中心 → 设备」查看各设备的累计上传、下载和合计。数据来自支持该功能的 GL.iNet 固件，覆盖范围由固件决定；外部独立客户端不会计入这里。

已在路由器 LuCI 实测协议选项和设备流量表，并在小火箭实测独立 WireGuard 客户端能联网、实际出口为首尔。发布包通过回归测试和可重复构建。全新 WARP 运行环境安装、APT 升级和运行环境恢复仍待独立实机验收。

下载 `imOK-0.2.37-4-install-kit.zip` 可一次取得完整插件 IPK、公开源码、安装说明和 SHA-256 校验文件。已有环境请先备份并保留旧版 IPK；标准 IPK 升级可能短暂重连。安装包不含第三方 WARP 运行环境、真实配置、私钥、私密订阅或现成节点。
