# WARP 安装与更新

此模块属于 v0.2.37-1 预发布版。现有环境的插件更新、版本检查与调度已实测；全新 WARP 安装、APT 升级和运行环境恢复仍待独立实机验收。v0.2.36-1 正式版继续保留。

## 第一次使用，从哪里开始？

进入 **imOK → WARP 安装与更新**。这是在路由器内安装 WARP，不是在手机或电脑安装客户端。安装好 imOK 插件，并不等于已经有了能运行 WARP 的独立 Linux 环境。

1. 本页自动检测处理器、OpenWrt 版本、可用空间、内存和必要系统组件。无需手动选择 CPU 架构。
2. 点击“自动下载并准备安装”。系统从固定官方地址下载 Debian ARM64 基础环境，核对固定大小与 SHA-256，再通过官方签名软件源下载 WARP 和必要依赖。**这个阶段不安装软件，不启动隧道。**
3. 文件准备完成后，点击“确认安装到路由器”，阅读说明、勾选并确认。安装仅使用已校验缓存；不在安装阶段临时下载未确认的软件。
4. 安装成功后，进入“账户与协议”登录自己的 Cloudflare 账户，再选出口和接管范围，最后手动开启。

默认流程不需要寻找运行环境包，也不需要手填校验码。仅打开页面会进行本机检测，不自动消耗下载流量；点击准备才开始下载，下载完成也不会自动安装。准备结果保留一天，过期后需重新准备；确认计划另有五分钟时效。官方源不可达、空间不足、签名或文件不符时停止，并显示失败原因，不使用未校验镜像绕过。

首次安装不能覆盖已有运行环境。检测到现有环境时，使用“检查与升级”，保留原环境用于回滚。当前自动安装只开放 ARM64 OpenWrt 24.10、Debian 12 bookworm 的受控路径；至少预留约 1.6 GB 可用存储，已知可用内存低于 192 MiB 时阻止准备。其他平台会明确提示不兼容，不强制安装。

### 高级：离线导入

官方源访问受限时，可展开“高级：离线导入运行环境”。从可信来源取得**未注册 Debian 12 ARM64 WARP 运行环境 `.tgz`** 和发布者的 SHA-256，上传后单独校验并确认安装。普通 `.deb`、插件 `.ipk`、带有他人注册身份的备份都不能在此导入。压缩包上限 256 MiB，解压上限 1.5 GiB。校验码只能证明文件与发布者提供的内容一致，不能替代对来源的信任。

本项目安装包不内置第三方 WARP 程序或账户。在线模式由用户设备直接从官方来源取得组件；离线导入是备用高级方式。

## 定期检查会不会断网？

默认每天检查一次，也可改为每三天、每周或关闭。后台以一分钟粒度查看是否到期；到期才读取 Cloudflare 官方稳定软件目录，不重连隧道、不切换出口，不自动安装任何程序。关闭 imOK 主线路时，版本检查仍可以进行。

页面分别展示本机版本、官方目录可用版本、最近成功检查、下次计划和检查失败原因。失败时保留历史时间，但不把历史目录当作当前最新结果。总览有首次安装、新版或检查失败的提示，异步读取，不阻塞总览开关和原有状态。

本机版本优先读取软件包数据库；对之前直接解包的旧环境，在独立子进程中只运行 `warp-cli --version` 识别，不凭安装包文件名猜版本。

## 怎么升级？

先准备本地或独立的路由器管理连接，到总览关闭 imOK，结束登录准备并等待运行占用释放，再回本页“检查更新”。升级可能涉及 WARP 的必要 Debian 依赖，但不会升级 OpenWrt 固件或主机软件。

点击“备份并升级”会先生成五分钟有效的确认计划，核对平台、现版本、新版本、账户配置和空间。勾选并确认后，后台在独立副本内下载和安装；官方签名、包版本、大小、SHA-256、自检及身份保留全部通过后，才保留原环境并提交文件替换。

安装阶段与程序自检使用维护子进程的无外网网络命名空间；不使用路由器的主线路命名空间。独立环境内禁止安装脚本启动服务，不挂载宿主 `/proc`、`/sys`、D-Bus 或网络设备；命令超时会终止本次命令组。没有必要的隔离权限时拒绝维护。

成功后仍保持关闭，需自行开启并检查隧道、实际出口及网站连通性。程序版本检测成功、程序自检成功和真实网络可用分别判断。

## 怎么回滚？

在“恢复副本与回滚”选择版本，明确确认后回滚。先验证副本完整性，保留当前 Cloudflare 注册资料和机器标识，再替换运行环境。副本不会自动删除；空间不够会拒绝维护。

文件替换失败会尝试恢复原环境；若断电导致替换尚未完成，持久事务标记会阻止隧道启动。可选恢复副本回滚；仅当能证明尚未替换或已经完成验证时，才允许“核对未完成维护”解除阻断。不凭空清除恢复记录。

这些恢复副本可能含私钥和注册身份，仅存放在路由器私有目录，**不能公开分享**。普通“备份迁移”配置导出不包含完整运行环境、恢复副本或私钥。本模块没有新增整机／固件恢复能力，系统重刷前仍需另行保护 `/opt/routepilot` 等私有资料。

## 来源与保护

- [Debian 官方镜像构建产物](https://github.com/debuerreotype/docker-debian-artifacts)提供基础环境。固定提交、压缩层大小与 SHA-256；仅允许固定 HTTPS 地址，不接受任意下载地址或镜像。
- [Cloudflare 官方软件源](https://pkg.cloudflareclient.com/)提供稳定版本目录、签名公钥及 WARP 软件包。
- 升级只使用 Cloudflare 源及 Debian bookworm / bookworm-security 官方签名源，允许补齐必要依赖；不添加不可信镜像、不关闭证书校验、不设置 `trusted=yes`。
- Cloudflare 公钥使用 2026-11-10 实际取得的 SHA-256 固定校验；公钥变化时阻止升级，需人工审查后再更新代码，不自动接受新信任根。
- 所有维护写入使用请求绑定、五分钟计划、一次性确认和运行环境互斥。启动实例、配置或身份变化会使原确认失效。仅打开页面、准备下载、上传文件、检查版本或修改检查频率，都不会安装、重启 WARP 或保存主线路配置。
- 导入器拒绝路径穿越、重复条目、特殊设备、关键目录链接及已注册身份；解压去掉 setuid / setgid 位。升级和回滚保留当前注册资料及机器标识。

## 当前验证边界

本地 macOS 采用临时目录和模拟进程测试维护事务；浏览器运行真实新模块、缓存 Argon 样式及隔离 RPC 适配器。官方目录、公钥和 Debian ARM64 基础环境已实际下载核对；基础环境已在临时目录解包验证结构，未执行其中 ARM64 程序。

**已在本地 ARM64 路由器完成插件更新、真实版本读取、官方目录检查、每日调度及运行中拒绝维护的验证**，详见[公开验证摘要](quality/warp-maintenance-0.2.37-1.md)。本次没有重启主线路或改变出口设置。

**尚未执行真实 WARP 首次安装 / APT 升级、真实 CGI 上传或硬件断电恢复。** 插件更新成功与模拟异常测试不代表这些运行环境写入操作已经实机验收。还未验证真实 Windows、iOS、Android 浏览器。首次安装、升级和恢复发布前仍需受控 ARM64 测试设备补验，不能以插件更新或模拟测试替代。

源码历史与公开旧版本保留在 GitHub tag / Release。源码回退和运行环境恢复应分别处理；回退前保护私有资料，不清空现有配置。
