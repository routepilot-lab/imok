# imok 使用说明

当前版本和验证边界统一见[项目 README](../../README.md)。安装前阅读[安装与恢复](INSTALL.zh-CN.md)。GL.iNet 管理页面通常为 `http://192.168.8.1:8080/cgi-bin/luci/admin/services/routepilot`；以自己设备的地址和端口为准。

## 四个主入口

1. **总览**：独立总开关、当前实际协议/出口、观测流量和连接记录。开关只提交开关，不保存其他未提交表单。
2. **Cloudflare 配置中心**：内含账户与协议、出口与分流、设备、DNS、Workers 和主线路入口六个独立页面。只加载本页表单与运行数据，账户目录和协议随后异步读取。页底保存只提交本页字段；Workers 页使用各自操作按钮，没有统一保存按钮。
3. **规则与更新**：内含“更新概况、来源与频率、规则管理、自定义分流”四个子页面，分别查看更新状态、选择或编辑来源、维护个人规则、配置始终直连/代理。域名规则依赖 DNS 结果，共用 CDN IP 可能影响同 IP 的其他域名。
4. **备份迁移**：导出非凭据设置；导入后总开关及设备策略关闭，主线路优先，入口偏好暂存待确认。身份、API token 和备用节点凭据不在备份内。

旧页面网址仍能跳到对应独立页面。名称地区筛选已删除；选择具体出口后，可检测真实出口 IP 和地区，不能用出口名字推断地区。

## 主线路入口

在 Cloudflare 配置中心进入独立的“主线路入口”页面，入口设置直接展示，无需展开。选择框保持紧凑，按方式显示字段：

- **默认：官方自动**：不填写地址，显式应用后清除固定入口，由官方客户端管理。
- **固定：从官方候选选择**：仅显示候选列表；当前环境只能应用 IPv4，IPv6 候选禁用。
- **手写：自定义 IPv4 入口**：仅显示公网 IPv4:端口输入，不保证任意地址都可用。

三种方式均保留官方客户端本地候选定期同步。同步只读取客户端已经下载的配置，不主动向云端强制拉取、不测速、不自动改换固定入口。“只保存同步间隔”不重连；“应用并检测”才提交入口，短暂撤回接管并可能宽带直连，重连后验证原预期出口；失败尝试恢复原入口。恢复无法确认时暂停，不能显示成功。

关闭期间提交的入口请求会等待原线路建立基线，不在原线路尚未就绪时消耗为失败结果。重复应用同一个入口也执行验证。检测是路由器侧隧道与原出口验证，不是优选测速或手机端验收。路由器的入口设置不会更新手机小火箭的独立配置。

## 分流与备用边界

一个主客户端同时共用一个出口，不支持每个设备同时选不同 VPS。账户目录列出可见虚拟网络，名称不是地区实测证明；VPS 出口须组织端已有正确路由。

按设备最多 8 条启用策略，MAC/IPv4 必须匹配租约；LAN 模式可选 1–8 个已有、启用且不重叠的私网接口。插件不会创建访客网或放开网段隔离。未选设备和网络不接管。

IPv6 可对受管范围阻断，或明确允许绕过代理直连；不提供 IPv6 代理。允许 IPv6 直连可能使用宽带真实出口。DNS 检测检查本机受管解析入口，不代表 LAN 设备端到端路径；历史检测会按连接上下文标记过期。

Workers 备用需要自己的 API 授权/节点、PROXYIP、独立检测和手动启用。部署成功不等于网络可用；不能自动切换主备用。Workers 页面内的入口优选属于 Workers，不能用来代替主线路的入口设置。API 保存不触发云部署，云端按钮会执行注明的操作；来源说明不代表维护方背书。

## 恢复与安全

主线路故障时按当前约定撤回接管并允许宽带直连；无法确认清理时报告未知。恢复阻断不会因普通保存、重启或删除历史显示而自动解除。完整事务证据一致时可显式“受控恢复原入口并验证”，输入 RESTORE 后恢复原入口及原预期出口，保留审计证据；损坏或不一致时继续阻断，按[恢复指南](INSTALL.zh-CN.md)排查，不能直接删除阻断文件。

不公开注册文件、token、登录链接、私人节点或完整设备配置。多页面提交互相独立并需请求确认。重新加载页面后使用当前操作格式；旧裸载荷脚本被拒绝，需要按开发说明迁移。

## 规则更新与回退

“更新概况”显示当前已保存频率、最近尝试、最近成功下载、下次检查时间和重试状态；订阅地址与更新间隔在“来源与频率”直接编辑。自动更新只在主线路开启并通过健康检查后执行，关闭时暂停；预计时间不保证网络不可用时准时完成。

“规则管理”可按中国 IP、中国域名、代理域名和直连域名浏览订阅原始内容、合并个人覆盖后的内容及本次增删，支持搜索和分页。已保存版本与当前运行版本分别确认；始终直连/代理规则在“自定义分流”编辑。旧版未记录的来源、增删信息不会追溯编造。

下载失败后以 5 分钟、30 分钟、2 小时间隔最多重试三次，之后恢复正常更新间隔。计划持久保存，服务重启不因丢失内存计时而重复下载。存储失败不会主动撤回健康线路。

某一分类原有至少 100 条、更新后不足原数量一半时，整批暂存为待确认候选，继续使用原规则。可浏览候选及其增删内容，再显式确认应用；候选有效期一天，确认绑定当前版本、候选版本和规则来源设置。过期或来源变化需重新更新。

“恢复上一版规则”会先展示确认，再发布上一份不同内容的订阅版本；重复下载相同内容不会挤掉该回退版本。个人覆盖和更新来源设置保持。关闭时仍不接管设备，运行中需等待版本生效确认；首次尚无上一版时不可回退。

## 页面显示与规则管理（0.2.35）

iMOK 2.0 沿用 Argon 的字体家族，在插件内统一字号、行高、间距、颜色和控件排版；通过清晰的标题、分组与状态说明保持页面紧凑。一级入口与内部导航均显示选中背景，来源预设和手工地址选择也有已选状态。

Cloudflare 六个独立页面去掉主标题编号，账户、入口、分流、设备和 DNS 按设置分组展示。Workers 通过部署与授权、PROXYIP 候选池、入口优选、导入检测与启用四个阶段组织；可展开全部设置，切换阶段保留草稿与操作结果。长帮助、危险操作说明及历史记录仍可展开。

“规则与更新”采用四个独立子页面，旧的规则页网址默认进入“更新概况”。

| 子页面 | 用途与保存范围 |
| --- | --- |
| 更新概况 | 查看更新进度、已保存/运行版本、当前下载版本来源和增删摘要；立即更新仅使用已保存来源 |
| 来源与频率 | 选择预设或编辑 HTTPS 地址、修改间隔；保存只提交本页来源与频率 |
| 规则管理 | 搜索、分页，维护个人新增与长期排除；每项变更独立确认，无整页保存 |
| 自定义分流 | 维护始终直连/代理的域名、IPv4/CIDR；只保存四组自定义分流字段 |

进入页面、切换导航和浏览规则不会自动保存草稿或切换线路；概况页立即更新不提交另一页未保存的输入。来源预设只改变本页输入，需保存才成为订阅地址。

来源地址可从已验证的项目/镜像中选择，也可编辑自定义 HTTPS 地址。当前提供 10 个可选预设：中国 IPv4 包含 17mon/IPIP、Misaka、Gaoyifan 等项目，域名为现有 Loyalsoldier 项目及其 README 列出的分发镜像。同项目 CDN 可能缓存滞后，独立项目也可能有覆盖差异；不会自动替换原配置。下载失败或内容不兼容时保留原已提交规则。验证见[本版检查摘要](../../docs/PUBLICATION_CHECKS.json)。

规则管理中可新增个人条目、长期排除订阅条目、撤销排除或删除个人新增，支持分类、搜索及 100 条分页。个人覆盖单独持久保存，实际规则为“订阅减去排除，再加个人新增”；普通订阅更新和订阅回退都不会清空个人覆盖。请求绑定订阅与个人覆盖两个版本，过期操作需刷新。不能清空当前分流模式必需的分类。

个人覆盖只影响使用该分类的模式；“始终直连/始终代理”使用自定义分流页的独立配置。保存成功和运行生效分别展示。个人覆盖文件已纳入路由器系统升级保留及本次私有备份；当前 v3 插件“设置导出”尚不包含个人新增/排除，跨设备迁移时需另行备份个人覆盖。
